### Overview

This is a presentation made through Qwen3.6-35B-A3B-MXFP4_MOE.gguf with Llama-cpp and Open-Code, to explain how to run an LLM locally with Llama-cpp and Open-Code to create slides for instance, like [these](/assets/html/prez-agentic.html). 

The model loaded some skills to make slides, I asked a neon terminal layout and ran it on a MacBook Pro (Apple M1 Max ARM chip architecture, 32GB memory, 8 cores), it took 4 hours.
